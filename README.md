# 🌸 공주님의 꽃꽂이 축제

**[게임핑 10분 게임 콘테스트 – 그때 그 게임편] 참가작**

플래시 게임의 향수를 담은  
**방향키 맞추기 기반 캐주얼 꽃꽂이 게임**입니다.

플레이 링크: https://www.game-ping.kr/games/flower-arrangement

---

## 🎮 게임 소개

**공주님의 꽃꽂이 축제**는  
꽃꽂이를 주제로 한 짧고 몰입감 있는 캐주얼 게임입니다.

상단에 표시되는 방향키를 맞춰 꽃을 꽃병에 꽂고,  
원하는 만큼 꽃을 넣었다면 **스페이스바**를 눌러 꽃꽂이를 완성하세요.

늦은 밤이 되기 전까지  
공주님이 축제를 성공적으로 마칠 수 있도록 도와주세요!

---

## 🕹️ 조작 방법

| 키 | 기능 |
|----|------|
| ↑ ↓ ← → | 방향키 입력 |
| Space | 꽃꽂이 완성 |

---

## ⏱️ 게임 특징

- 짧은 플레이 타임, 빠른 몰입
- 방향키 입력 기반의 간단한 조작
- 꽃꽂이를 완성하는 소소한 성취감
- 플래시 게임 특유의 캐주얼한 감성

---

## 🎨 제작 의도

어릴 적 쉽게 접할 수 있었던  
**주니어 사이트의 플래시 게임**에서 느꼈던 감성을 떠올리며 제작했습니다.

단순한 규칙 속에서도  
개성 있는 캐릭터와 직관적인 연출로  
짧은 시간 동안 부담 없이 즐길 수 있는 게임을 목표로 했습니다.

이번 프로젝트를 통해 **벡터 이미지를 처음 제작**해 보았으며,  
작업 난이도로 인해 초기 계획보다 분량은 줄었지만  
그만큼 핵심적인 재미에 집중하고자 했습니다.

부디 편안한 마음으로 즐겨주시면 감사하겠습니다 🌷
